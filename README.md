# 桌面宠物 (DesktopPet)

一个基于 Avalonia 的 Windows 桌面宠物。透明、置顶、点击穿透的全屏窗口里，有一只会自己走动的蜘蛛、蟑螂、甲虫、蚂蚁、蜈蚣、瓢虫，或者你自己的图片。

## 功能

- **七种宠物**：蜘蛛（8 条腿）、蟑螂、甲虫、蚂蚁、瓢虫（各 6 条腿）、蜈蚣（18 对腿，转弯时身体会弯曲），以及用你自己的图片做身体的自定义宠物（见下文）。托盘图标右键或设置窗口里切换，选择会记住，托盘图标也会跟着宠物变化。
- **步态**：每条腿由两节骨的 IK 驱动，按交替步态迈步，膝盖始终朝外。
- **随机移动**：走几个随机路径点，走走停停，走完后停在原地。
- **点宠物**：宠物会快速转向并冲刺到附近的 B 点，再以正常速度走向随机的 C 点。
- **喂食与不同的食物**：按住 `Ctrl` 再点其他位置，在点击处放一份食物，食物种类由当前宠物决定。屏幕上同时只有一份，托盘菜单里可以关闭喂食。

  | 宠物 | 食物 |
  | --- | --- |
  | 蜘蛛 | 苍蝇（黑色剪影） |
  | 蟑螂 | 面包屑 |
  | 甲虫 | 树叶 |
  | 蚂蚁 | 糖粒 |
  | 蜈蚣 | 小虫 |
  | 瓢虫 | 树叶 |
  | 自定义 | 面包屑 |

- **吃东西动画**：宠物跑到食物旁会先停下，前腿抬起，头一点一点，食物逐渐变小，约 1.3 秒后吃完消失。吃的时候点宠物会被打断去冲刺，食物保留，之后继续去吃。
- **跟随鼠标**：托盘菜单开启后，宠物离光标超过一定距离就走过去，靠近后停下并保持一段距离。有食物时先去吃食物，点宠物冲刺也优先。
- **空闲小动作**：宠物停下时会随机抖触角、原地转头、抬前腿、沿屏幕边缘爬一段，或者沿别的窗口的边缘爬一段（上下左右任选一条边）。
- **全屏自动隐藏**：前台是游戏或全屏视频时，宠物自动隐藏并暂停，退出全屏后恢复（可在托盘菜单关闭）。
- **开机自启**：托盘菜单勾选后，会注册一个最高权限的登录计划任务，开机登录时自动启动，不会弹 UAC。
- **记住设置**：宠物选择和各个开关保存在 `%AppData%\DesktopPet\settings.json`，下次启动自动读取。
- **多显示器**：窗口覆盖所有显示器组成的虚拟桌面。
- **单实例**：同一时间只能运行一个，桌面上不会出现两只宠物。
- **点击穿透**：窗口平时不拦截鼠标，不影响你操作其他软件。光标靠近宠物（睡着时除外）或按住 `Ctrl` 时，窗口会临时接收点击，这样点宠物和放食物就不会同时点到下面的软件。窗口带不抢焦点的样式。
- **大小与速度**：大小分小 / 中 / 大三档，速度分慢 / 正常 / 快三档，腿长、步幅和点击范围都会跟着大小缩放。
- **活动范围**：可以限制宠物只在某一块显示器上活动（按从左到右排序，序号超出显示器数量时退回所有显示器）。
- **躲鼠标**：光标很快地冲到宠物身边时，宠物会朝反方向冲刺躲开，躲完有 4 秒冷却。按住 `Ctrl`（要喂食）、有食物或开启跟随鼠标时不躲。
- **睡觉**：空闲时会随机睡着，头顶出现 Zzz，身体轻微起伏。点它、放食物或鼠标冲过来都会弄醒它。
- **饥饿**：约 8 分钟从 0 涨到满。越饿走得越慢、空闲间隔越短、越爱抖触角，吃东西会降低饥饿值。
- **夜间模式**：23:00 到 06:00 之间走得更慢，也更容易睡着。
- **脚印**：走路时落脚处留下淡淡的小圆点，约 2.5 秒后淡出，同时最多 80 个。
- **蜘蛛网**：蜘蛛沿边爬行结束时，会在停下的位置织一张小网，约 25 秒后淡出，同时最多 6 张。只有蜘蛛会织。
- **音效**：程序内合成的两种短音（吃东西、冲刺 / 躲避），不需要音频文件。默认关闭，可在托盘菜单或设置窗口开启。
- **设置窗口**：托盘菜单里的“设置…”，把宠物、大小、速度、活动范围、退出快捷键和各个开关集中在一起，改动实时生效并保存。
- **检查更新**：启动 8 秒后自动查一次 GitHub Releases 上的最新版本，也可以在托盘菜单手动检查。有新版本时可以前往下载、忽略此版本或稍后再说。查不到网络时静默跳过。
- **自定义退出快捷键**：托盘菜单里有几个预设，也可以在设置窗口或配置文件里自己写，格式如 `Ctrl+Alt+Q`、`Ctrl+Shift+F12`，至少一个修饰键加一个字母键或 F1~F12，写错会回退到 `Ctrl+Shift+Q`。
- **性能**：宠物活动时约 16 毫秒刷新一次，静止时降到约 33 毫秒，被全屏应用隐藏时降到 250 毫秒。

## 操作

| 操作 | 效果 |
| --- | --- |
| 点击宠物身体附近 | 冲刺后继续随机走动 |
| 按住 `Ctrl` 点击其他位置 | 放一份食物，宠物去吃 |
| 不按 `Ctrl` 点击其他位置 | 无反应（点击仍会落到下面的程序） |
| 托盘图标右键 → 蜘蛛 / 蟑螂 / 甲虫 / 蚂蚁 / 蜈蚣 / 瓢虫 / 自定义 | 切换宠物（场上的食物会被清掉） |
| 托盘图标右键 → 宠物大小 / 移动速度 / 活动范围 / 退出快捷键 | 选择对应档位 |
| 托盘图标右键 → 启用喂食 / 全屏时自动隐藏 / 跟随鼠标 / 开机自启 / 音效 / 自动检查更新 | 开关对应功能 |
| 托盘图标右键 → 检查更新 / 设置… | 手动检查新版本 / 打开设置窗口 |
| 托盘图标右键 → 退出，或退出快捷键（默认 `Ctrl+Shift+Q`） | 退出程序 |

## 配置文件

`%AppData%\DesktopPet\settings.json`，首次运行自动生成，文件损坏或值不合法时回退到默认值。

| 字段 | 含义 | 默认 |
| --- | --- | --- |
| `Pet` | `spider` / `roach` / `beetle` / `ant` / `centipede` / `ladybug` / `custom` | `spider` |
| `Size` | `small` / `medium` / `large` | `medium` |
| `Speed` | `slow` / `normal` / `fast` | `normal` |
| `Monitor` | 0 = 所有显示器，n = 第 n 块（从左到右） | `0` |
| `ExitHotkey` | 退出快捷键，如 `Ctrl+Alt+Q` | `Ctrl+Shift+Q` |
| `SoundEnabled` | 音效 | `false` |
| `AutoCheckUpdate` | 启动后自动检查更新 | `true` |
| `IgnoredVersion` | 被“忽略此版本”的版本号，自动检查时不再提示 | 空 |
| `FeedingEnabled` | 是否允许喂食 | `true` |
| `AutoHideFullscreen` | 前台全屏应用时自动隐藏 | `true` |
| `FollowMouse` | 跟随鼠标 | `false` |
| `AutoStart` | 开机自启（启动时以系统里计划任务的实际状态为准） | `false` |

## 自定义宠物

把一张 PNG 图片放到 `%AppData%\DesktopPet\custom.png`，然后在托盘菜单或设置窗口里选“自定义”。图片会显示成一个约 80×80 像素的身体（等比缩放），配上 6 条会走路的腿。

- 请让图片里的“头”朝上，宠物前进时头朝向运动方向。
- 每次切换到自定义宠物时都会重新读取图片，改了图片不用重启程序。
- 图片不存在或读取失败时，只会显示腿。

## 运行要求

- Windows 10 及以上
- [.NET 8 运行时](https://dotnet.microsoft.com/download/dotnet/8.0)（不带运行时的发布版需要）
- **需要管理员权限**：程序在清单里请求管理员，手动启动时会弹出 UAC。否则点不到在管理员权限下运行的软件上方的宠物。开机自启走计划任务，不会弹。

## 构建

```bash
git clone <本仓库地址>
cd Spider
dotnet build -c Debug
```

启动前先退出正在运行的实例，否则 `DesktopPet.exe` 被占用，编译会失败。

## 发布（单文件，不带运行时）

```bash
dotnet publish -c Release -r win-x64 --self-contained false ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:DebugType=none -p:DebugSymbols=false -p:SatelliteResourceLanguages=en -o publish
```

输出是 `publish\DesktopPet.exe`。不建议加 `PublishTrimmed`，Avalonia 的 XAML 加载依赖反射，裁剪后容易启动失败。

## 自动发布（GitHub Actions）

`.github/workflows/release.yml` 会在推送以 `v` 开头的标签时，用 `windows-latest` 编译单文件的 `DesktopPet.exe`，并自动创建 GitHub Release（带自动生成的更新说明）。

发布一个新版本：

1. 把 `Spider.csproj` 里的 `<Version>` 改成要发布的版本，例如 `1.2.0`。
2. 提交并推送到 `main`。
3. 打标签并推送：

   ```bash
   git tag v1.2.0
   git push origin v1.2.0
   ```

4. 到仓库的 Actions 页面查看运行结果，成功后 Releases 页面会出现 `DesktopPet.exe`。

注意：

- 标签不能重复使用，已有的标签（例如 `v1.0.1`、`v1.1.0`）不能再用。
- 标签去掉 `v` 后必须是 `1.2.0` 这样的数字版本号，程序的“检查更新”才能解析。`Spider.csproj` 的 `<Version>` 要和标签保持一致，否则程序会一直提示有新版本。
- 如果 Release 创建失败，到仓库 Settings → Actions → General → Workflow permissions，确认允许读写权限。
- 发布出来的 exe 不带运行时，用户需要安装 .NET 8 运行时。

## 项目结构

```
Spider/
├── Program.cs              入口，单实例互斥体
├── App.axaml(.cs)          托盘图标与菜单
├── AppSettings.cs          配置文件读写
├── AutoStart.cs            开机自启（schtasks 计划任务）
├── UpdateChecker.cs        通过 GitHub Releases 检查新版本
├── NoticeWindow.cs         简单的提示窗口（更新提示等）
├── SettingsWindow.cs       设置窗口（纯代码构建）
├── SoundFx.cs              程序内合成的音效
├── MainWindow.axaml(.cs)   透明窗口、运动逻辑、输入轮询、食物与吃东西、跟随鼠标、攀爬窗口边缘
├── Views/
│   ├── SpiderView.axaml    蜘蛛的外形与样式
│   ├── RoachView.axaml     蟑螂的外形与样式
│   ├── BeetleView.axaml    甲虫的外形与样式
│   ├── AntView.axaml       蚂蚁的外形与样式
│   ├── CentipedeView.axaml 蜈蚣（体节与腿由代码生成）
│   ├── LadybugView.axaml   瓢虫的外形与样式
│   └── CustomView.axaml    自定义宠物（读取 custom.png 做身体）
├── Assets/*.png            各宠物的托盘图标
├── .github/workflows/
│   └── release.yml         推送 v* 标签时自动编译并创建 Release
└── app.manifest            管理员权限清单
```

每种宠物的外形和样式分别放在各自的 View 里，互不共用。体型参数（腿长、落点、缩放、食物种类）在 `MainWindow.axaml.cs` 的 `Pet` 对象里。

## 调整

以下常量都在 `MainWindow.axaml.cs` 顶部：

- 移动速度：`BaseSpeed`、`TurnRate`；冲刺：`DashSpeed`、`DashTurn`；追食物：`ChaseSpeed`、`ChaseTurn`。
- 吃东西时长：`EatTime`；跟随鼠标的出发 / 停下距离：`FollowFar`、`FollowNear`。
- 沿边爬行速度：`CrawlSpeed`；空闲小动作间隔：`IdleMin`、`IdleMax`。
- 每种宠物的腿长和落点：构造函数里对应 `Pet` 的 `LenA`~`LenD`、`Reach`、`Rest`，以及每对腿的缩放系数 `LegScale`。
- 食物：`Pet.Food`（`fly` / `crumb` / `leaf` / `sugar` / `worm`）和 `Pet.FoodScale`。想加新食物，在 `AddFly` 的 `switch` 里加一项并写一个对应的 `MakeXxx()`。

## 已知限制

- 光标靠近宠物或按住 `Ctrl` 时窗口会临时拦截点击，所以宠物附近那一小块区域暂时点不到下面的程序，把光标移开即可恢复。
- 躲鼠标的速度阈值、睡眠概率、脚印大小等手感参数都是估的，没有在高 DPI 或多显示器缩放不一致的环境里实测过。
- 开机自启用 `schtasks` 创建的任务，默认在笔记本使用电池时可能不会启动；程序挪了位置后，需要关掉再重新勾选一次“开机自启”。
- 沿窗口边缘爬只在开始时读取一次窗口位置，爬行中窗口被移动或被别的窗口遮挡，宠物不会跟着变化。宠物窗口是置顶的，所以总是画在最上层。
- 多显示器且缩放比例不一致时，活动范围和点击坐标可能有偏差。
- 外形是用 XAML 图形手绘的，并不追求完全写实。
